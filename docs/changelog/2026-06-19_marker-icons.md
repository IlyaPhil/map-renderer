# 2026-06-19 — PNG-иконки для навигационных знаков

## Задача

Реализовать отображение буёв и навигационных знаков не только геометрическими фигурами,
но и в виде PNG-иконок с возможностью выбора режима и изменения размера через публичные методы.
Иконки — индивидуальные для каждого S57-класса (вариант Б).

## Подход

### MapFeature — поле s57class

Добавлено поле `QString s57class` в структуру `MapFeature`. Хранит конкретный S57-класс
объекта (`BCNLAT`, `BOYLAT`, `LIGHTS` и т.д.), в отличие от `LayerType`, который даёт
только группу (Beacons / Buoys).

### S57Loader — передача s57class

В `processGeometry()` добавлен параметр `const QString& s57class`. При создании каждого
`MapFeature` класс записывается в поле `s57class`. Рекурсивные вызовы для Multi*-геометрий
тоже передают класс по цепочке.

### MapWidget — режимы и иконки

Добавлены публичные методы:
- `setMarkerMode(MarkerMode)` — переключает режим `Shapes` ↔ `Icons` с перерисовкой
- `setMarkerSize(int pixels)` — задаёт размер иконки в пикселях с перерисовкой

Приватный метод `iconFor(s57class)`:
1. Ищет файл `<папка_exe>/icons/<s57class>.png`
2. При нахождении загружает и кэширует (`QMap<QString, QPixmap> m_iconCache`)
3. При отсутствии генерирует программную заглушку: цветной круг с аббревиатурой класса
   (буи — красные, навигационные знаки — оранжевые)

В `drawFeature()` при режиме `Icons` для слоёв Beacons/Buoys рисует `QPixmap`,
масштабированный до `m_markerSize`, через `painter.drawPixmap(QRect, pixmap)`.
При отсутствии иконки — прозрачный fallback через `break`.

### MainWindow — UI-элементы

- Спинбокс «Размер знаков: N px» (диапазон 8–128, по умолчанию 24) — вызывает `setMarkerSize()`
- Кнопка-переключатель «Знаки: фигуры» / «Знаки: иконки PNG» — вызывает `setMarkerMode()`

## Проблемы и решения

- Иконки не подхватывались при правильном расположении файлов — причина: имена файлов
  не совпадали с S57-классами (регистр, сокращения). Решение: точное соответствие
  `<s57class>.png` → `LIGHTS.png`, `BCNLAT.png` и т.д.
- IDE показывала ложные ошибки в S57Loader.cpp сразу после Write — диагностика была
  сформирована против кэшированного старого заголовка. После сборки ошибок не было.

## Результат

- Режим иконок работает: PNG загружаются из `build/icons/`, кэшируются, масштабируются
- Режим фигур сохранён без изменений
- При отсутствии PNG-файла показывается информативная заглушка
- Размер иконок меняется через спинбокс в UI и через `setMarkerSize()` из кода
