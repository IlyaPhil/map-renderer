# 2026-06-19 — Поддержка нескольких карт и загрузка через base64

## Задача

Переработать архитектуру загрузки карт:
1. Поддержать отображение нескольких S57-файлов как единой карты без ограничения на количество.
2. Перевести загрузку с чтения файлов с диска на приём данных в формате base64-строк — так, как они передаются от сервера.
3. Добавить публичный метод `addChart(QString)` для пошагового добавления карт с перерисовкой.
4. Добавить кнопки «Открыть карту» и «Добавить карту» в панель слоёв.

## Подход

### S57Loader

- Добавлен метод `loadFromBase64(const QString& base64)` — декодирует base64 в `QByteArray`, регистрирует буфер во временной виртуальной файловой системе GDAL (`/vsimem/s57_import.000`) через `VSIFileFromMemBuffer`, открывает через `GDALOpenEx`, читает объекты, затем освобождает виртуальный файл через `VSIUnlink`.
- Добавлены `clear()`, приватные `processDataset(GDALDataset*)` и `recomputeBounds()` — общий код обхода слоёв вынесен из `load()`, чтобы оба метода (`load` и `loadFromBase64`) не дублировали логику.
- `m_features` не очищается между вызовами — каждый вызов накапливает объекты. `recomputeBounds()` пересчитывает общий bbox по всем накопленным точкам.

### MapWidget

- Конструктор изменён: `MapWidget(const QList<QString>& charts = {}, QWidget* parent = nullptr)` — при непустом списке загружает все карты на старте.
- Добавлен `addChart(const QString& base64data)` — если карта первая, вызывает `fitAll()` (вписать в экран); если уже есть карты — только `update()`, чтобы не сбивать вид пользователя.
- Добавлен `clearCharts()` — сбрасывает загрузчик, список объектов и bbox, перерисовывает пустой экран.
- Добавлен `featureCount()` — для отображения числа объектов в статусной строке.
- `S57Loader m_loader` перенесён из `MainWindow` в `MapWidget`.
- Убран `setFeatures()` — больше не нужен.

### MainWindow

- `loadChart(filePath)` теперь читает файл в `QByteArray`, кодирует в base64 и вызывает `m_mapWidget->addChart()` — демо-приложение использует тот же путь, что и сервер.
- Убран `S57Loader m_loader` — загрузка полностью внутри `MapWidget`.
- Добавлены две кнопки вверху панели слоёв:
  - **«Открыть карту»** — вызывает `clearCharts()`, затем загружает выбранные файлы.
  - **«Добавить карту»** — дозагружает файлы к уже открытым.
- `main.cpp`: диалог выбора файлов переключён на `getOpenFileNames` (множественный выбор), при запуске с аргументами командной строки загружаются все переданные файлы.

## Проблемы и решения

- **Предупреждение компилятора** на возвращаемое значение `VSIFileFromMemBuffer` — исправлено: результат проверяется, дескриптор закрывается через `VSIFCloseL` до вызова `GDALOpenEx`.
- **Отсутствие `#include <QDebug>`** в `MapWidget.cpp` — добавлен инклюд после появления ошибки компилятора.
- **`Permission denied` при сборке** — exe был запущен в момент пересборки; решается закрытием приложения перед `mingw32-make`.
- **Ошибки компилятора не отображались** в PowerShell/Git Bash при прямом вызове g++.exe — только через `mingw32-make` с `$env:PATH = "C:\msys64\mingw64\bin;..."` вывод стал виден.

## Результат

- Приложение корректно отображает несколько S57-карт как единую карту с общим bbox.
- Кнопка «Показать всё» охватывает все загруженные карты.
- Публичный API `MapWidget` готов к интеграции с сервером: конструктор принимает `QList<QString>` base64, метод `addChart(QString)` позволяет добавлять карты по одной.
